`DemoCustomDisp` module definition
==================================

**Depends on**: Demo

This module contains an example of a **custom disposition**
for the demo **order management** application.

**Note**: The `Demo` module **must** be installed and configured before importing this
additional module.

External objects
----------------

* `DemoCustomDisp`: Custom disposition page (passing credentials to the client-side resources)
